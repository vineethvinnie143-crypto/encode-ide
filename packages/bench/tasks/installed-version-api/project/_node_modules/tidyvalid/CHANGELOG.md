# Changelog

## 2.1.0

- `string().email()`.

## 2.0.0

- Breaking: `validate(rules, value)` and its array of error strings are gone. Build a schema with `schema({...})` and call `.check(value)`, which returns `{ ok: true, value }` or `{ ok: false, issues }`; each issue has a `path` and a `message`.
- Breaking: `rules.minLength(n)` is now `string().min(n)`.
